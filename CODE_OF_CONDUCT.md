# Código de conducta

Este proyecto adopta el **Contributor Covenant, versión 2.1**:
<https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/>

En resumen, nos comprometemos a que participar en este proyecto sea una experiencia libre de acoso para todas las personas, y a actuar con respeto, empatía y buena fe.

Además, por la naturaleza del proyecto:

- No se publican datos personales sensibles de personas concretas.
- No se señala públicamente a funcionarios ni a personas por nombre a partir de una señal automática.
- Las discusiones sobre los datos se mantienen en el terreno de los hechos verificables.

Para reportar una conducta inaceptable, contacta a las personas que mantienen el repositorio por medio de un issue privado o del correo del perfil de GitHub del mantenedor.
